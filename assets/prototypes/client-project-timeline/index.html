Demo Controls

Milestone mode shows completed project stages only. Continuous mode adds half-step states for in-between moments, such as reviews, checkpoints, or approvals in progress.
Choose how many major stages the workflow should include. Each count uses a complete start-to-finish milestone set.
Select the current stage. In continuous mode, half-step values show in-between progress states.
Auto uses the horizontal timeline when space allows and switches to the vertical timeline on smaller screens. Horizontal and Vertical force a specific layout.

Prototype Purpose

This prototype makes workflow states testable before production implementation, including milestone counts, in-between progress states, and client-facing status details.

How this could work on your website

This type of timeline could be managed manually through editable CMS fields, connected to structured project data, or updated from an internal system/API depending on the workflow. For WordPress, it could be built as an ACF-powered block or template component. For larger applications, the same front-end pattern could consume project status data from an API.
